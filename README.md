# MIRA-science schema

This is a working version of the schema we developed during the [MIRA](https://www.mira.science) workshop.

- Vocabulary: http://purl.org/mira-science/mira#
- Transport format: https://purl.org/mira-science/mira.jsonld
- Validator: https://mira.science/mira.shacl
- Human-readable walkthrough: https://mira-science.github.io/epistack-competition/walk.html
- Making-of: https://mira.science/blog/what-we-built-at-the-mira-kickoff/



The current version builds upon and refers to schema work done for [Discourse Graphs](https://discoursegraphs.com), especially around the notion of Evidence.   The MIRA schema is now meant to stand alone, and each platform, including Discourse Graphs, should inherit that common schema.

This repository uses [LinkML](https://linkml.io) to describe the schemas. The current version of the generated documentation can be found [here](https://mira.science/schema/).

We invite participants to submit pull requests to the [repository](https://github.com/mira-science/schema) for proposed improvements.
